짧은 요약(Abstract) :


이 논문에서는 대형 언어 모델(LLM)이 수학 문제 해결 및 과학 질문 응답과 같은 복잡한 작업을 수행하기 위해 점점 더 긴 형식의 다단계 추론에 의존하고 있다는 점을 강조합니다. 기존의 신뢰도 추정 방법은 전체 추론 과정을 단일 스칼라 점수로 축소하여 신뢰도가 어떻게 변화하는지를 무시합니다. 이로 인해 신뢰도 추정이 응답 길이나 장황함과 같은 표면적인 요소에 민감해지고, 올바른 추론과 자신감 있게 잘못된 응답을 구별하는 데 어려움을 겪습니다. 본 연구에서는 신뢰도 신호를 단계별로 특성화하기 위해 신호 시간 논리(Signal Temporal Logic, STL)를 사용합니다. STL 패턴을 통해 올바른 응답과 잘못된 응답의 신뢰도 신호를 구별할 수 있는 시간적 공식을 발견하였으며, 이러한 통찰을 바탕으로 하여 하이퍼네트워크를 통해 STL 블록에 매개변수를 제공하는 신뢰도 추정 접근 방식을 개발했습니다. 여러 추론 작업에 대한 실험 결과, 우리의 신뢰도 점수가 기존 방법보다 더 잘 보정되었음을 보여주었습니다.



This paper emphasizes that large language models (LLMs) increasingly rely on long-form, multi-step reasoning to solve complex tasks such as mathematical problem solving and scientific question answering. Existing confidence estimation methods typically reduce the entire reasoning process to a single scalar score, ignoring how confidence evolves throughout the generation. As a result, these methods are often sensitive to superficial factors such as response length or verbosity, and struggle to distinguish correct reasoning from confidently stated errors. We propose to characterize the stepwise confidence signal using Signal Temporal Logic (STL). Using STL patterns, we discover temporal formulas that distinguish the confidence signals of correct and incorrect responses. Based on these insights, we develop a confidence estimation approach that informs STL blocks with parameter hypernetworks. Experiments on multiple reasoning tasks show that our confidence scores are more calibrated than the baselines.

# Methodology



이 논문에서는 대형 언어 모델(LLM)의 신뢰도 추정 문제를 해결하기 위해 신호 시간 논리(Signal Temporal Logic, STL)를 활용한 새로운 방법론을 제안합니다. 이 방법론은 LLM의 긴 형식의 다단계 추론 과정에서 신뢰도가 어떻게 변화하는지를 모델링하는 데 중점을 두고 있습니다.

#### 1. 모델 아키텍처
제안된 모델은 LLM의 응답을 여러 개의 연속적인 세그먼트로 나누어 각 세그먼트에 대한 신뢰도를 계산합니다. 각 세그먼트의 신뢰도는 해당 세그먼트에 포함된 토큰의 확률을 평균하여 산출됩니다. 이 신뢰도 신호는 STL을 사용하여 시간적 패턴으로 분석됩니다. STL은 신뢰도 신호의 시간적 제약을 명시하는 형식적 언어로, 이를 통해 올바른 응답과 잘못된 응답의 신뢰도 패턴을 구별할 수 있는 공식을 발견합니다.

#### 2. 훈련 데이터
모델은 다양한 추론 작업에 대한 레이블이 있는 입력-출력 쌍을 사용하여 훈련됩니다. 이 데이터는 각 응답이 주어진 입력에 대해 올바른지 여부를 나타내는 이진 정답 레이블을 포함하고 있습니다. 훈련 과정에서 모델은 STL 공식을 최적화하여 올바른 응답과 잘못된 응답을 구별하는 데 필요한 신뢰도 패턴을 학습합니다.

#### 3. 특별한 기법
- **신뢰도 신호의 단계적 모델링**: LLM의 응답을 여러 단계로 나누어 각 단계에서의 신뢰도를 계산하고, 이를 STL을 통해 분석하여 신뢰도 패턴을 추출합니다.
- **하이퍼네트워크**: 질문에 따라 STL 블록의 파라미터를 조정하기 위해 하이퍼네트워크를 사용합니다. 이 하이퍼네트워크는 입력 질문과 신뢰도 신호를 기반으로 각 질문에 적합한 파라미터를 생성합니다.
- **이해 가능성**: STL 공식을 사용하여 신뢰도 추정의 해석 가능성을 높입니다. 각 STL 공식은 신뢰도 패턴을 명확하게 설명할 수 있는 구조를 제공하여, 모델의 실패 모드를 감사할 수 있게 합니다.

이러한 방법론을 통해 제안된 모델은 기존의 신뢰도 추정 방법보다 더 잘 보정된 신뢰도 점수를 제공하며, 다양한 추론 작업에서 우수한 성능을 보입니다.

---




This paper proposes a novel methodology for confidence estimation in large language models (LLMs) using Signal Temporal Logic (STL). The approach focuses on modeling how confidence evolves throughout the long-form, multi-step reasoning processes of LLMs.

#### 1. Model Architecture
The proposed model segments the responses generated by the LLM into multiple consecutive segments, calculating the confidence for each segment. The confidence for each segment is derived by averaging the probabilities of the tokens contained within that segment. This confidence signal is then analyzed using STL to capture temporal patterns. STL serves as a formal language for specifying temporal constraints on the confidence signal, allowing for the discovery of formulas that distinguish between correct and incorrect responses.

#### 2. Training Data
The model is trained using labeled input-output pairs from various reasoning tasks. This data includes binary correctness labels indicating whether each response is correct for the given input. During training, the model optimizes the STL formulas to learn the necessary confidence patterns that differentiate correct from incorrect responses.

#### 3. Special Techniques
- **Stepwise Confidence Modeling**: The model divides the LLM's responses into multiple steps, calculating confidence at each step and analyzing these using STL to extract confidence patterns.
- **Hypernetworks**: A hypernetwork is employed to adapt the parameters of the STL blocks based on the question. This hypernetwork generates question-specific parameters based on the input question and the confidence signal.
- **Interpretability**: By utilizing STL formulas, the model enhances the interpretability of confidence estimation. Each STL formula provides a clear structure that can explain confidence patterns, allowing for the auditing of the model's failure modes.

Through this methodology, the proposed model offers better-calibrated confidence scores compared to existing estimation methods and demonstrates superior performance across various reasoning tasks.

# Results



이 논문에서는 대형 언어 모델(LLM)의 신뢰도 추정 방법을 제안하고, 이를 신호 시간 논리(Signal Temporal Logic, STL)를 사용하여 모델의 추론 과정에서 신뢰도가 어떻게 변화하는지를 분석합니다. 실험은 네 가지 추론 벤치마크인 GAOKAO-Math, CLadder, SciQ, Big-Bench-Hard (BBH)에서 수행되었습니다. 

#### 경쟁 모델
제안된 STL 기반 신뢰도 추정 방법은 여러 기존 방법들과 비교되었습니다. 여기에는 로짓 기반 방법(AveLogit), 자기 평가(Self-Eval), 자기 일관성(Self-Consistency), 내부 상태 기반 방법(InternalInspector) 등이 포함됩니다. 각 방법은 동일한 데이터 분할 및 추론 설정에서 평가되었습니다.

#### 테스트 데이터
테스트 데이터는 각 벤치마크에서 제공된 샘플로 구성되었으며, 각 샘플에 대해 정답 레이블이 부여되었습니다. 예를 들어, BBH는 23개의 도전적인 추론 작업으로 구성되어 있으며, 총 6511개의 샘플이 포함되어 있습니다. SciQ는 13,679개의 과학 질문으로 구성되어 있습니다.

#### 메트릭
신뢰도 추정 품질은 세 가지 주요 메트릭을 사용하여 평가되었습니다:
1. **Expected Calibration Error (ECE)**: 예측된 신뢰도와 실제 정확도 간의 차이를 측정합니다.
2. **Brier Score (BS)**: 예측된 확률과 이진 정답 간의 평균 제곱 오차를 측정합니다.
3. **AUROC (Area Under the Receiver Operating Characteristic Curve)**: 이진 분류의 성능을 평가하는 지표입니다.

#### 비교 결과
실험 결과, 제안된 방법은 모든 벤치마크에서 기존 방법들보다 더 나은 성능을 보였습니다. 특히, ECE와 Brier Score에서 제안된 방법이 가장 낮은 값을 기록하며, 신뢰도 추정의 정확성을 높였습니다. 예를 들어, Qwen3-8B 모델을 사용한 경우, ECE는 0.005로 나타났으며, 이는 기존 방법들보다 현저히 낮은 수치입니다. 

또한, STL 기반 방법은 신뢰도 추정의 해석 가능성을 제공하며, 각 추론 단계에서의 신뢰도 변화를 명확히 드러내는 장점이 있습니다. 반면, 기존의 로짓 기반 방법은 길이 편향에 영향을 받으며, 신뢰도 변화를 충분히 반영하지 못하는 한계를 보였습니다.





This paper proposes a confidence estimation method for large language models (LLMs) using Signal Temporal Logic (STL) to analyze how confidence evolves during the reasoning process. Experiments were conducted on four reasoning benchmarks: GAOKAO-Math, CLadder, SciQ, and Big-Bench-Hard (BBH).

#### Competing Models
The proposed STL-based confidence estimation method was compared against several existing methods, including logit-based methods (AveLogit), self-evaluation (Self-Eval), self-consistency (Self-Consistency), and internal state-based methods (InternalInspector). All methods were evaluated under identical data splits and inference settings.

#### Test Data
The test data consisted of samples provided by each benchmark, with ground truth labels assigned to each sample. For instance, BBH comprises 23 challenging reasoning tasks with a total of 6,511 samples, while SciQ consists of 13,679 science questions.

#### Metrics
The quality of confidence estimation was evaluated using three main metrics:
1. **Expected Calibration Error (ECE)**: Measures the difference between predicted confidence and empirical accuracy.
2. **Brier Score (BS)**: Measures the mean squared error between predicted probabilities and binary ground truth outcomes.
3. **AUROC (Area Under the Receiver Operating Characteristic Curve)**: Evaluates the performance of binary classification.

#### Comparison Results
The experimental results showed that the proposed method outperformed existing methods across all benchmarks. Notably, it achieved the lowest values in both ECE and Brier Score, enhancing the accuracy of confidence estimation. For example, using the Qwen3-8B model, the ECE was recorded at 0.005, significantly lower than that of competing methods.

Additionally, the STL-based approach provides interpretability in confidence estimation, clearly revealing confidence changes at each reasoning step. In contrast, existing logit-based methods are affected by length bias and fail to adequately reflect confidence evolution.

4. **피규어 4**: 네 가지 추론 벤치마크에서 올바른 추론과 잘못된 추론을 나타내는 STL 패턴의 쌍별 유사성을 보여줍니다. 잘못된 패턴이 더 높은 구조적 유사성을 보이는 경향이 있음을 나타냅니다.

5. **피규어 6**: STL 블록을 사용한 신뢰도 정량화 파이프라인을 보여줍니다. 훈련 중에 STL 공식을 발견하고, 테스트 시 고정된 STL 블록을 적용하여 단계별 신뢰도 신호를 처리합니다.
