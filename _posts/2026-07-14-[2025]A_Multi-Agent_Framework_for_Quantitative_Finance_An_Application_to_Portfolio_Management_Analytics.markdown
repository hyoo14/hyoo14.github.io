This paper highlights the scarcity of AI frameworks capable of autonomously performing complex tasks and quantitative analysis on structured data within the field of quantitative finance. To address this gap, we introduce a novel Multi-Agent framework tailored for portfolio management and research tasks. Our framework facilitates mathematical modeling and data analytics by dynamically generating executable code. The innovative multi-agent architecture includes specialized components and agents for reflection, summarization, and financial expertise, which coordinate to enhance problem-solving abilities. We present a comprehensive empirical evaluation on portfolio management-specific tasks, addressing a critical gap in current research. Our findings reveal that the proposed Multi-Agent framework vastly outperforms Single-Agent frameworks, demonstrating its practical utility across various task categories. By using dynamic code generation with the agent’s multi-step reasoning capabilities, we broaden the range of tasks that can be successfully addressed.

# Methodology



이 논문에서 제안하는 다중 에이전트 프레임워크는 포트폴리오 관리 분석을 위해 설계된 혁신적인 아키텍처입니다. 이 프레임워크는 여러 개의 전문화된 에이전트로 구성되어 있으며, 각 에이전트는 특정 작업을 수행하도록 설계되었습니다. 이 시스템은 다음과 같은 주요 구성 요소로 이루어져 있습니다.

1. **Base-Agent**: 이 에이전트는 문제 해결의 중심 역할을 하며, 사용자가 제공한 데이터 파일과 쿼리를 기반으로 작업을 수행합니다. Base-Agent는 Python 코드 실행 도구를 사용하여 관련 코드를 생성하고, 이를 통해 최종 답변을 도출합니다.

2. **Insights Agents**: 이 그룹은 여러 개의 에이전트로 구성되어 있으며, 데이터 요약, 질문 생성, 금융 전문 지식 제공 및 쿼리 정제를 담당합니다. 
   - **Data Summarizer**: 데이터 파일을 분석하고, 패턴을 도출하며, 대량의 금융 데이터를 간결한 요약으로 압축합니다. 이 에이전트는 결측값을 식별하고 필요한 열 정의를 추가합니다.
   - **Question Generator**: 사용자의 쿼리를 입력으로 받아 Base-Agent가 답변하는 데 필요한 금융 정의, 공식 및 정보를 결정합니다.
   - **Finance Expert**: Question Generator가 생성한 질문에 대한 답변을 제공하여 Base-Agent가 필요한 정보를 확보할 수 있도록 돕습니다.
   - **Query Refiner**: 사용자의 쿼리를 개선하여 명확성과 초점을 높이고, 데이터 특정 용어를 포함하여 더 나은 품질의 쿼리를 생성합니다.

3. **Reflection Agent**: 이 에이전트는 Base-Agent의 출력을 반복적으로 검증하고 비판하여 잠재적인 오류나 누락을 식별하고 수정 제안 및 대안 접근 방식을 제시합니다. 이를 통해 생성된 답변의 정확성과 완전성을 보장합니다.

이 프레임워크는 LLM(대형 언어 모델)의 능력을 활용하여 복잡한 정량적 작업을 수행할 수 있도록 설계되었습니다. 특히, 금융 모델링에서의 도메인 이해, 논리적 코드 생성, 복잡한 다단계 추론 및 금융 특정 쿼리 해석과 같은 주요 과제를 해결하는 데 중점을 두고 있습니다. 

훈련 데이터는 내부적으로 수집된 데이터와 템플릿 질문을 사용하여 생성된 합성 데이터로 구성되어 있습니다. 이 데이터는 포트폴리오 관리자와 연구자들의 입력을 바탕으로 현실적이고 관련성 있는 질문을 포함하고 있습니다. 

이러한 다중 에이전트 프레임워크는 포트폴리오 관리 및 자산 관리 분야에서의 실용성을 높이며, 사용자가 보다 정확하고 신뢰할 수 있는 분석 결과를 얻을 수 있도록 돕습니다.

---




The multi-agent framework proposed in this paper is an innovative architecture designed for portfolio management analytics. This framework consists of multiple specialized agents, each designed to perform specific tasks. The system is composed of the following key components:

1. **Base-Agent**: This agent serves as the decision-making hub, evaluating the user-provided data file and query to perform tasks. The Base-Agent utilizes a Python code execution tool to generate relevant code, which is then used to derive the final answer.

2. **Insights Agents**: This group consists of several agents responsible for data summarization, question generation, financial expertise provision, and query refinement.
   - **Data Summarizer**: Analyzes the uploaded data file, derives patterns, and condenses large volumes of financial data into concise summaries. This agent identifies missing values and adds necessary column definitions.
   - **Question Generator**: Takes the user query as input and determines the relevant financial definitions, formulas, and information needed by the Base-Agent to answer the query.
   - **Finance Expert**: Provides answers to the questions generated by the Question Generator, ensuring that the Base-Agent has the necessary information.
   - **Query Refiner**: Improves the user query to enhance clarity and focus, incorporating data-specific jargon to produce a better-quality query for the Base-Agent to answer.

3. **Reflection Agent**: This agent iteratively validates and critiques the outputs of the Base-Agent, identifying potential errors or omissions and suggesting corrections and alternative approaches. This additional layer of scrutiny ensures the precision and completeness of the generated answers.

The framework is designed to leverage the capabilities of Large Language Models (LLMs) to perform complex quantitative tasks. It specifically addresses key challenges in financial modeling, such as domain understanding, logical code generation, complex multi-step reasoning, and finance-specific query interpretation.

The training data consists of internally collected data and synthetic data generated using template questions. This data includes realistic and relevant questions based on input from portfolio managers and researchers.

Overall, this multi-agent framework enhances the practicality of portfolio management and asset management, helping users obtain more accurate and reliable analytical results.

# Results



이 논문에서는 제안된 다중 에이전트 프레임워크의 성능을 평가하기 위해 100개의 도메인 특정 질문을 포함하는 데이터셋을 사용하였습니다. 이 질문들은 난이도에 따라 '쉬운' 질문과 '어려운' 질문으로 분류되었으며, 각각의 질문은 정량적 금융 분석과 관련된 다양한 주제를 다루고 있습니다. 평가 결과는 다음과 같은 네 가지 모델을 비교하여 도출되었습니다:

1. **Base-Agent**: 단일 도구 호출 기반의 에이전트.
2. **Base-Agent + Reflection**: 반영 기능이 추가된 Base-Agent.
3. **Base-Agent + Insights**: 통찰력 기능이 추가된 Base-Agent.
4. **Multi-Agent**: 제안된 다중 에이전트 모델.

각 모델은 10회씩 질문에 답변하도록 하여 일관성과 정확성을 측정하였습니다. 평가 메트릭으로는 Pass@k (k=1, 2, 5, 10)를 사용하였으며, 이는 모델이 정답을 얼마나 정확하게 제공했는지를 나타냅니다.

#### 전체 성능
테이블 2에서는 각 모델의 Pass@k 점수를 보여줍니다. Multi-Agent 모델은 Pass@1에서 46%의 정확도를 기록하며, Base-Agent + Insights(43.89%), Base-Agent + Reflection(39%), Base-Agent(39.59%)보다 높은 성능을 보였습니다. 모든 평가 메트릭에서 Multi-Agent 모델이 가장 높은 점수를 기록하였으며, 이는 포트폴리오 관리자의 요구를 충족하는 데 효과적임을 나타냅니다.

#### 질문 유형 및 난이도에 따른 성능 분석
테이블 3에서는 질문의 난이도에 따른 성능을 분석하였습니다. Multi-Agent 모델은 '어려운' 질문에서 Base-Agent에 비해 Pass@1 점수가 34% 더 높았으며, Pass@10 점수는 58% 더 높았습니다. 이는 Multi-Agent가 복잡한 다단계 추론이나 깊은 금융 전문 지식이 필요한 질문에서 더 나은 성능을 발휘함을 보여줍니다. '쉬운' 질문에서도 Multi-Agent가 가장 높은 성능을 보였지만, 상대적인 개선폭은 '어려운' 질문에 비해 작았습니다.

#### 대체 모델을 사용한 평가
추가적으로, OpenAI의 o3-mini 모델을 사용하여 Multi-Agent 모델의 성능을 비교하였습니다. 결과적으로, Multi-Agent 모델은 모든 메트릭에서 Base-Agent보다 우수한 성능을 보였으며, 이는 제안된 다중 에이전트 프레임워크의 강력함을 다시 한번 입증합니다.

이러한 결과들은 제안된 다중 에이전트 프레임워크가 포트폴리오 관리 및 자산 관리 분석에서의 실용성을 높이고, 복잡한 금융 분석 작업을 보다 효과적으로 수행할 수 있도록 설계되었음을 보여줍니다.

---




In this paper, the performance of the proposed Multi-Agent framework was evaluated using a dataset comprising 100 domain-specific questions. These questions were categorized into 'easy' and 'hard' based on their difficulty, covering various topics related to quantitative financial analysis. The evaluation results were derived by comparing four different models:

1. **Base-Agent**: A single tool-calling agent.
2. **Base-Agent + Reflection**: The Base-Agent enhanced with reflection capabilities.
3. **Base-Agent + Insights**: The Base-Agent augmented with insights capabilities.
4. **Multi-Agent**: The proposed multi-agent model.

Each model was tasked with answering each question ten times to measure consistency and accuracy. The evaluation metrics used were Pass@k (k=1, 2, 5, 10), which indicate how accurately the model provided correct answers.

#### Overall Performance
Table 2 presents the Pass@k scores for each model. The Multi-Agent model achieved a Pass@1 accuracy of 46%, outperforming the Base-Agent + Insights (43.89%), Base-Agent + Reflection (39%), and Base-Agent (39.59%). The Multi-Agent model consistently scored the highest across all evaluation metrics, demonstrating its effectiveness in addressing the needs of portfolio managers.

#### Performance Analysis by Question Type and Difficulty
Table 3 analyzes performance based on the difficulty of the questions. The Multi-Agent model achieved a 34% higher Pass@1 score on 'hard' questions compared to the Base-Agent, and a 58% higher Pass@10 score. This indicates that the Multi-Agent excels in answering questions that require complex multi-step reasoning or deep financial expertise. The Multi-Agent also performed best on 'easy' questions, although the relative improvement was not as significant as for 'hard' questions.

#### Evaluation Using Alternative Models
Additionally, the performance of the Multi-Agent model was compared using OpenAI's o3-mini model. The results showed that the Multi-Agent model outperformed the Base-Agent across all metrics, further validating the robustness of the proposed multi-agent framework.

These results highlight that the proposed Multi-Agent framework is designed to enhance practical applications in portfolio management and asset management analytics, effectively addressing complex financial analysis tasks.

     - "Perform regression analysis between a stock's returns and a macroeconomic factor."

#### Specific Tasks

- **Task 1**: "Calculate the variance of NFLX Equity."
  - **Input**: Price data for NFLX stock (e.g., closing prices by date)
  - **Output**: Variance value of NFLX stock

- **Task 2**: "What is the correlation coefficient between Convertible Arbitrage and Fixed Income Arbitrage returns from 2010 to 2015?"
  - **Input**: Return data for both strategies (e.g., monthly returns)
  - **Output**: Correlation coefficient between the two strategies

These questions reflect the analytical tasks that portfolio managers frequently perform, and the multi-agent framework collaborates through various agents to provide answers to these inquiries.
